Manual Checks Recommended

  • Browser smoke test: Start the app (python run.py) and verify the landing page loads, clicking "Get Started" transitions to the analyzer, and the upload form works end-to-end.
  • Hash routing: Verify #analyzer, #history, #scan=ID URLs route correctly between landing and dashboard views.
  • Production SECRET_KEY: Set SECRET_KEY environment variable before any deployment. The dev fallback is intentionally insecure.
  • HTTPS in production: The app has no built-in TLS. Use a reverse proxy (nginx, Caddy) or cloud load-balancer to terminate HTTPS.
  • Stale duplicate files: static/js/dashboard (1).js and templates/index (1).html are now redundant duplicates. They can be deleted to avoid confusion, but this is cosmetic — they have no effect on the running application.
