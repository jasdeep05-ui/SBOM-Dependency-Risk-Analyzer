How the analyzer works

Upload a requirements.txt or package.json file (up to 2 MB). The file is parsed and then deleted from the server immediately.

  1. 01ParseReads package names and version specifiers from Python and Node.js dependency files.
  2. 02Generate SBOMBuilds a CycloneDX 1.5 bill of materials you can view and download.
  3. 03Scan with OSVChecks exact (pinned) versions against OSV.dev. Ranges and unpinned entries are reported as skipped, never as safe.
  4. 04Score & exportA custom 0–100 project score (not a CVSS score), plus PDF and CSV reports.
